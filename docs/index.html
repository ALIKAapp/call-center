Open this page in Google Chrome or Microsoft Edge on a computer. Other browsers cannot talk to a phone.
PhoneReady to make calls
  1. On the phone open Settings → About phone and tap Build number 7 times.
  2. Go to Developer options and switch on USB debugging.
  3. Plug the phone into this computer, press Connect phone and pick it from the list.
  4. Unlock the phone and tap Allow (tick “Always allow” so it remembers this computer).
Phone not showing up?
  • Use a cable that carries data, not a charge-only cable.
  • On the phone, pull down the notification bar and set USB to File transfer.
  • Close Android Studio or any other “adb” program on this computer.
  • Windows: if it still does not appear, install the Google USB driver once.
